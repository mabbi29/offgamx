# OffGamX — Wide Gaming Portal

> "Play the Best Free Browser Games in Wide Mode."
> Live domain: [offgamx.site](https://offgamx.site)

OffGamX is a modern, high-performance browser gaming portal featuring 25+ original, fully playable games engineered from scratch with TypeScript, React, HTML5 Canvas, WebGL, and Three.js.

## Highlights
- **25+ Full Native Games**: Racing, Arcade, Shooting, Platformer, Tower Defense, Puzzle, Runner, Brawler, Sports, Simulation, Submarine Exploration, Roguelike, Blackjack, Checkers, Sudoku, Mahjong, and FreeCell.
- **Edge-to-Edge Wide Mode**: Fully responsive ResizeObserver-backed game viewports without dead margins or black side pillars.
- **Persistent Progression**: Level tracking, personal best scores, favorites, and player reviews persisted via `localStorage`.
- **Zero-Latency Audio**: Built-in Web Audio API synthesizers producing procedural sound effects (jump, laser, blast, engine rumble, chip deal, chimes) without heavy external assets.
- **Keyboard & Mobile Touch Controls**: Seamless dual support for desktop keyboards (WASD, Arrows, Space) and dynamic on-screen touch overlays.
- **Clean Aesthetic**: Bright, high-contrast, premium slate/cyan/indigo palette adhering to anti-slop visual discipline.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/<user>/offgamx.git
cd offgamx

# Install dependencies
npm install

# Run local development server (port 3000)
npm run dev

# Build for production
npm run build
```
